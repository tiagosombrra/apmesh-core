# AP Mesh Core — Decision Records

Each qualified contract, scientific stage, algorithm-selection decision, dependency admission, or scope change should produce a focused decision record in this directory.

A decision record must state:

- question;
- alternatives considered;
- literature/standards consulted;
- assumptions and admissible input class;
- implementation/evidence revision;
- verification and regression evidence;
- retained limitations;
- final decision;
- next admissible action.

Decision records do not replace the authoritative roadmap. They provide the evidence and rationale behind roadmap status changes.

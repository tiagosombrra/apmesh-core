# AP Mesh Core — Process Entry Point

The AP Mesh Core documentation intentionally has one planning source of truth and a small set of supporting contracts.

## Source of truth

`docs/APMESH_CORE_ROADMAP.md` is the single authoritative implementation roadmap and status ledger.

GitHub issues are execution trackers only. They MUST NOT become an alternative roadmap. If an issue and the roadmap disagree, the roadmap must be updated or the issue corrected before work continues.

## Continuation entry point

`docs/APMESH_CORE_STATE.md` is the compact handoff document for a new work session. It points to the current active work but does not replace the roadmap.

## Mandatory process

`docs/process/APMESH_CORE_SCIENTIFIC_WORKFLOW.md` defines the repeated investigation, evidence, documentation, literature-review, and end-of-stage regression workflow.

## Supporting documents

- `docs/contracts/` — architecture/numeric/experiment contracts.
- `docs/research/REFERENCE_REGISTER.md` — reviewed literature, standards, and best-practice sources.
- future `docs/decisions/` — qualification/closure decisions.
- future experiment manifests/certificates — reproducible computational evidence.

## Update rule

A meaningful implementation or scientific decision is incomplete until the authoritative roadmap and continuation state accurately describe the resulting repository state.

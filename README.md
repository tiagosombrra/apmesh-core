# AP Mesh Core

Greenfield C++23 scientific core for AP Mesh. Foundation is qualified in the
declared WSL toolchain envelope. Point/Vector Semantics and Minimal Small
Linear Algebra are also qualified. Transformations, topology, curves, surfaces,
patches, meshing, sizing, and adaptation are not implemented.

Start with `docs/APMESH_CORE_STATE.md`, then read
`docs/APMESH_CORE_ROADMAP.md`.
